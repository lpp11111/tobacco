# train/ — 模型训练

## 用途

4 个 YOLO 模型（extra_small/medium/small/large）的原始训练流程，包含训练脚本、训练数据集、训练结果和统计分析。

## 目录结构

```
train/
├── train_extra_small.py        ← extra_small 模型训练脚本
├── train_medium.py             ← medium 模型训练脚本
├── train_small.py              ← small 模型训练脚本
├── train_large.py              ← large 模型训练脚本
├── yolo26n.pt                  ← YOLOv8-nano 预训练权重 (5.3 MB)
│
├── data/                       ← 训练数据集（按模型分类）
│   ├── extra_small/            ← extra_small 数据集（2类：healthy/disease）
│   │   ├── train/images/, labels/
│   │   ├── valid/images/, labels/
│   │   └── test/images/, labels/
│   ├── medium/                 ← medium 数据集（2类：healthy/disease）
│   │   ├── train/, valid/, test/
│   ├── small/                  ← small 数据集（4类病害分级）
│   │   ├── train/, valid/, test/
│   └── large/                  ← large 数据集（1类：tobacco）
│       ├── train/, valid/, test/
│
├── data_result/                ← 训练结果输出
│   ├── extra_small_train/      ← extra_small 训练结果
│   │   ├── weights/best.pt, last.pt, epoch*.pt
│   │   ├── results.csv, results.png
│   │   └── confusion_matrix.png, Box*_curve.png ...
│   ├── medium_train/           ← medium 训练结果
│   ├── small_train/            ← small 训练结果
│   └── large_train/            ← large 训练结果
│
├── statistics/                 ← 统计分析
│   ├── stats_extra_small.py    ← extra_small 统计脚本
│   ├── stats_extra_small.json  ← extra_small 统计结果
│   ├── stats_medium.py         ← medium 统计脚本
│   ├── stats_medium.json       ← medium 统计结果
│   ├── stats_large.py          ← large 统计脚本
│   └── stats_large.json        ← large 统计结果
│
└── annotations/                ← 标注文件（预留目录）
```

## 使用方法

```bash
# 训练各模型
python train/train_extra_small.py
python train/train_medium.py
python train/train_small.py
python train/train_large.py

# 运行统计分析
python train/statistics/stats_medium.py
```

## 数据集格式

每个数据集遵循 YOLO 格式：
```
data/模型名/
├── train/
│   ├── images/    ← 图片文件
│   └── labels/    ← 标签文件（class_id x_center y_center width height）
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```

## 训练结果文件说明

| 文件 | 说明 |
|------|------|
| `weights/best.pt` | 验证集上表现最好的权重 |
| `weights/last.pt` | 最后一轮训练的权重 |
| `weights/epoch*.pt` | 各轮次权重（可用于继续训练） |
| `results.csv` | 每轮训练的 loss/mAP 等指标 |
| `results.png` | 训练曲线图（loss、mAP 随 epoch 变化） |
| `confusion_matrix.png` | 混淆矩阵 |
| `BoxF1/PR/P/R_curve.png` | F1/PR/Precision/Recall 曲线 |
| `labels.jpg` | 标签分布统计图 |
| `train_batch*.jpg` | 训练批次可视化 |
| `val_batch*_labels.jpg` | 验证集真实标注 |
| `val_batch*_pred.jpg` | 验证集预测结果 |

## 训练完成的模型对应关系

| 训练脚本 | 数据集 | 输出权重 | 最终位置 |
|----------|--------|----------|----------|
| `train_extra_small.py` | `data/extra_small/` | `data_result/extra_small_train/weights/best.pt` | `models/best_extra_small.pt` |
| `train_medium.py` | `data/medium/` | `data_result/medium_train/weights/best.pt` | `models/best_medium.pt` |
| `train_small.py` | `data/small/` | `data_result/small_train/weights/best.pt` | `models/best_small.pt` |
| `train_large.py` | `data/large/` | `data_result/large_train/weights/best.pt` | `models/best_large.pt` |
