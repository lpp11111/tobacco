# check/ — 模型评估脚本与结果

## 用途

在 t 数据集上评估各 YOLO 模型的性能指标（Precision、Recall、mAP50、mAP50-95），用于横向对比不同模型的效果。

## 文件说明

### 评估脚本

| 文件 | 说明 |
|------|------|
| `check_transfer_t.py` | **综合评估** — 一次评估全部 7 个模型（extra_small/medium/small/large/scratch/transfer/finetune），输出综合对比表和各模型单独结果 |
| `check_transfer_medium.py` | 仅评估 medium 模型在 t 数据集上的性能 |
| `check_transfer_small.py` | 仅评估 small 分割模型，4 类→2 类映射后评估 |
| `check_transfer_large.py` | 仅评估 large 分割模型 |

### 评估结果（transfer_check/）

| 文件 | 说明 |
|------|------|
| `transfer_check/det_models_comparison.csv` | 检测模型综合对比（extra_small/medium/scratch/transfer/finetune） |
| `transfer_check/seg_models_comparison.csv` | 分割模型综合对比（small/large） |
| `transfer_check/transfer_results_extra_small.csv` | extra_small 模型单独评估结果 |
| `transfer_check/transfer_results_medium.csv` | medium 模型单独评估结果 |
| `transfer_check/transfer_results_small.csv` | small 模型单独评估结果 |
| `transfer_check/transfer_results_large.csv` | large 模型单独评估结果 |
| `transfer_check/transfer_results_scratch.csv` | scratch 模型单独评估结果 |
| `transfer_check/transfer_results_transfer.csv` | transfer 模型单独评估结果 |
| `transfer_check/transfer_results_finetune.csv` | finetune 模型单独评估结果 |

## 使用方法

```bash
# 综合评估所有模型
python check/check_transfer_t.py --model all

# 仅评估单个模型
python check/check_transfer_t.py --model finetune

# 单独评估 medium 模型
python check/check_transfer_medium.py
```

## 评估指标说明

| 指标 | 说明 |
|------|------|
| **Precision** | 精确率：预测为正的样本中，真正为正的比例 |
| **Recall** | 召回率：真正为正的样本中，被正确预测的比例 |
| **mAP50** | IoU=0.5 时的平均精度均值 |
| **mAP50-95** | IoU=0.5~0.95（步长 0.05）的平均精度均值 |
| **Mask mAP** | 分割 mask 的平均精度（仅分割模型） |

## 最新评估结果

| 模型 | 类型 | mAP50 | mAP50-95 |
|------|------|-------|----------|
| finetune | det | 0.826 | 0.576 |
| transfer | det | 0.693 | 0.468 |
| scratch | det | 0.649 | 0.446 |
| medium | det | 0.631 | 0.372 |
| extra_small | det | 0.004 | 0.001 |
| small | seg | 0 | 0 |
| large | seg | 0 | 0 |

> 最佳检测模型：**finetune**（mAP50=0.826）
> 注：small/large 为分割模型，在 t 检测数据集上无法正常评估。
