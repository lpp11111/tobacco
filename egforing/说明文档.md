# egforing/ — 示例目录（标注检查与预测结果）

## 用途

存放各模型原始标注数据的检查脚本和预测结果，用于验证标注质量和模型预测效果。

## 目录结构

```
egforing/
├── annotations/                ← 各模型的原始标注数据与检查脚本
│   ├── check_annotations_extra_small.py  ← extra_small 标注检查脚本
│   ├── check_annotations_large.py        ← large 标注检查脚本
│   ├── check_annotations_medium.py       ← medium 标注检查脚本
│   ├── check_annotations_small.py        ← small 标注检查脚本
│   ├── check_annotations_t.py            ← t 数据集标注检查脚本
│   │
│   ├── orign_extra_small/      ← extra_small 原始数据集
│   │   ├── train/              ← 训练集（images + labels）
│   │   ├── valid/              ← 验证集
│   │   └── test/               ← 测试集
│   ├── orign_large/            ← large 原始数据集
│   │   └── valid/
│   ├── orign_medium/           ← medium 原始数据集
│   │   └── valid/
│   ├── orign_small/            ← small 原始数据集
│   │   └── valid/
│   └── orign_t/                ← t 数据集原始标注
│       ├── train/
│       ├── val/
│       └── test/
│
└── predict_res/                ← 预测结果
    ├── origin_median_for_finetune/      ← 原始 medium 模型评估结果
    │   └── transfer_results_medium.csv
    └── finetuned_median_for_finetune/   ← 微调后 medium 模型评估结果
        └── transfer_results_finetune.csv
```

## 标注检查脚本

| 脚本 | 说明 |
|------|------|
| `check_annotations_extra_small.py` | 检查 extra_small 数据集标注质量 |
| `check_annotations_large.py` | 检查 large 数据集标注质量 |
| `check_annotations_medium.py` | 检查 medium 数据集标注质量 |
| `check_annotations_small.py` | 检查 small 数据集标注质量 |
| `check_annotations_t.py` | 检查 t 数据集标注质量 |

## 预测结果对比

`predict_res/` 目录用于对比微调前后 medium 模型的效果：

| 目录 | 说明 | mAP50 |
|------|------|-------|
| `origin_median_for_finetune/` | 原始 medium 模型评估结果（微调前基准） | 0.631 |
| `finetuned_median_for_finetune/` | 微调后 medium 模型评估结果 | 0.826 |

> 微调后 mAP50 提升 30.9%（0.631 → 0.826）

## 使用方法

```bash
# 检查标注质量
python egforing/annotations/check_annotations_medium.py

# 查看预测结果对比
# 打开 predict_res/ 下的 CSV 文件
```
