## 预测脚本

### predict.py

**作用**: 封装好的预测函数，支持任意格式、任意大小图片的检测

**命令行使用**:
```bash
python project/predict.py image.jpg                    # 使用中尺度模型
python project/predict.py image.jpg --model_type finetuned  # 使用微调模型
python project/predict.py image.jpg --save --output ./results  # 保存标注图
```

**Python API使用**:
```python
from predict import predict

result = predict('image.jpg')
print(f"检测到 {result['total_detections']} 个目标")
print(f"类别: {result['class_counts']}")
```

**支持的模型类型**:
- `large`: 大尺度模型 (1类)
- `medium`: 中尺度模型 (4类)
- `small`: 小尺度模型 (4类)
- `finetuned`: 微调模型 (4类)

**输入格式**: PNG, JPG, JPEG, TIF, TIFF, BMP, WebP

**输出内容**:
- `total_detections`: 检测目标总数
- `class_counts`: 各类别数量统计
- `avg_confidence`: 平均置信度
- `annotated_image`: 标注后的图片(可选保存)

## 微调训练脚本

### finetune_medium.py

**作用**: 在t数据集上微调中尺度模型，统一类别和标签格式

**使用**:
```bash
python project/finetune_medium.py
```

**步骤**:
1. 创建微调数据集（格式转换 + 类别映射）
2. 训练50 epochs
3. 评估微调后模型精度
4. 保存微调模型到 `models/best_medium_finetuned.pt`

**类别映射**:
- grow_tobacco(0) → healthy(1)
- disease_tobacco(1) → light_disease(0)
- others(2) → 跳过

**训练结果**:
| 指标 | 值 |
|------|-----|
| mAP50 | 0.339 |
| Precision | 0.877 |
| Recall | 0.227 |
