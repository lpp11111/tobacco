# tobacco_project 脚本说明

## 脚本清单

### 1. tif_process.py — TIF影像烟草苗检测主脚本

**作用**: 处理大尺寸TIF遥感影像，自动检测烟草苗并生成矢量边界文件，支持NDVI辅助过滤

**流程**:
```
输入TIF → 切片(640x640) → 模型检测 → [NDVI过滤] → 坐标转换 → NMS去重 → 矢量输出
```

**使用**:
```bash
# 纯RGB检测
python tif_process.py --tif rs_data/result.tif --model ../train/small/small_train/weights/best.pt

# NDVI辅助检测（过滤NDVI<0.3的检测结果）
python tif_process.py --tif rs_data/result.tif --model ../train/small/small_train/weights/best.pt --ndvi --ndvi_threshold 0.3
```

**参数**:
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--tif` | TIF文件路径 | rs_data/result.tif |
| `--model` | 模型权重路径 | ../train/small/small_train/weights/best.pt |
| `--output` | 输出目录 | output |
| `--tile_size` | 切片大小 | 640 |
| `--overlap` | 重叠像素数 | 64 |
| `--ndvi` | 启用NDVI辅助检测 | 禁用 |
| `--ndvi_threshold` | NDVI过滤阈值 | 0.3 |

**输出**:
- `output/tobacco_plants.shp` — 纯RGB检测矢量边界
- `output/tobacco_plants_ndvi.shp` — NDVI辅助检测矢量边界（含NDVI属性）
- `output/detection_results.csv` — 纯RGB检测结果表格
- `output/detection_results_ndvi.csv` — NDVI辅助检测结果表格（含NDVI列）

**NDVI辅助原理**:
- 利用TIF第4波段(NIR)和第3波段(RED)计算NDVI
- NDVI = (NIR - RED) / (NIR + RED)
- NDVI范围[-1, 1]，健康植被通常在0.3-0.8之间
- 过滤NDVI值低于阈值的检测结果，减少非植被区域的误检

### 2. slice_tif.py — TIF影像切片工具

**作用**: 将大尺寸TIF遥感影像切分为640×640的小切片，保存为PNG格式，支持RGB和NDVI切片

**流程**:
```
输入TIF → 滑动窗口切片 → 有效性过滤 → RGB/NDVI保存
```

**使用**:
```bash
# 仅保存RGB切片
python slice_tif.py --tif rs_data/result.tif

# 保存RGB和NDVI切片
python slice_tif.py --tif rs_data/result.tif --ndvi

# 自定义切片大小和重叠
python slice_tif.py --tif rs_data/result.tif --tile_size 512 --overlap 32 --ndvi
```

**参数**:
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--tif` | TIF文件路径 | rs_data/result.tif |
| `--output` | 输出目录 | chunks |
| `--tile_size` | 切片大小 | 640 |
| `--overlap` | 重叠像素数 | 64 |
| `--no_rgb` | 不保存RGB切片 | 保存 |
| `--ndvi` | 保存NDVI彩色切片 | 不保存 |

**输出**:
- `chunks/rgb/tile_XXX_XXX.png` — RGB切片（按行列编号命名）
- `chunks/ndvi/tile_XXX_XXX.png` — NDVI彩色切片（伪彩色渲染）

**切片规则**:
- 滑动窗口重叠64像素，确保边界区域完整检测
- 自动过滤全黑无效切片（RGB三通道最大值均为0）
- 输出为PNG格式，自动转换为8位灰度

### 3. test_tif_process.py — 测试脚本

**作用**: 快速验证功能，仅处理前50个切片，输出测试结果

**使用**:
```bash
python test_tif_process.py
```

**输出**:
- `output/test_results.csv` — 测试结果（含NDVI计算示例）

### 4. generate_comparison.py — 对比图生成脚本

**作用**: 生成纯RGB检测和NDVI辅助检测两种方法的对比分析图（PNG格式）

**使用**:
```bash
python generate_comparison.py
```

**输出对比图**:
| 文件名 | 说明 |
|--------|------|
| `count_comparison.png` | 检测目标数量对比柱状图 |
| `confidence_distribution.png` | 置信度分布对比直方图 |
| `ndvi_distribution.png` | NDVI值分布直方图 |
| `spatial_distribution.png` | 空间分布对比散点图 |
| `comparison_table.png` | 检测方法对比表格 |

**数据来源**:
- `output/detection_results.csv` — 纯RGB检测结果
- `output/detection_results_ndvi.csv` — NDVI辅助检测结果

## 使用步骤

1. **生成切片**: `python slice_tif.py --ndvi`
2. **测试**: `python test_tif_process.py`
3. **纯RGB检测**: `python tif_process.py`
4. **NDVI辅助检测**: `python tif_process.py --ndvi --ndvi_threshold 0.3`
5. **生成对比图**: `python generate_comparison.py`
