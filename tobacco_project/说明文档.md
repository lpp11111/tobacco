# tobacco_project/ — TIF 大图处理子项目

## 用途

处理大尺寸 TIF 遥感图像，支持切片、模型推理、结果汇总、GeoJSON/Shapefile 输出，以及 RGB 与 NDVI 检测结果对比分析。

## 目录结构

```
tobacco_project/
├── slice_tif.py                ← TIF 切片工具
├── tif_process.py              ← 全流程处理（切片→推理→汇总→输出）
├── generate_comparison.py      ← RGB vs NDVI 结果对比分析
│
├── chunks/                     ← TIF 切片输出
│   ├── rgb/                    ← RGB 切片（640×640 PNG，约 500+ 张）
│   └── ndvi/                   ← NDVI 切片（640×640 PNG，约 500+ 张）
│
├── output/                     ← 处理输出结果
│   ├── detection_results.csv       ← RGB 检测结果
│   ├── detection_results_ndvi.csv  ← NDVI 检测结果
│   ├── tobacco_plants.shp/.dbf/.prj/.shx/.cpg  ← RGB 烟草 Shapefile
│   ├── tobacco_plants_ndvi.shp/.dbf/.prj/.shx/.cpg ← NDVI 烟草 Shapefile
│   ├── comparison_table.png        ← 对比表图
│   ├── confidence_distribution.png ← 置信度分布图
│   ├── count_comparison.png        ← 数量对比图
│   ├── ndvi_distribution.png       ← NDVI 分布图
│   └── spatial_distribution.png    ← 空间分布图
│
└── rs_data/                    ← 遥感原始数据
    ├── result.tif              ← 遥感影像 TIF 文件
    ├── result.tif.aux.xml      ← TIF 辅助文件
    ├── result.tif.ovr          ← TIF 金字塔文件
    ├── result.tfw              ← 世界文件（地理坐标）
    └── result.prj              ← 投影文件
```

## 脚本说明

### slice_tif.py — TIF 切片工具

- **功能**：将大尺寸 TIF 遥感图像切为 640×640 小块
- **输入**：`rs_data/result.tif`
- **输出**：`chunks/rgb/` 和 `chunks/ndvi/` 目录下的 PNG 切片
- **参数**：`tile_size=640`, `overlap=64`（默认）

### tif_process.py — 全流程处理

- **功能**：TIF 大图 → 切片 → 模型推理 → 结果汇总 → GeoJSON/Shapefile 输出
- **核心类**：`TIFProcessor`
- **输入**：TIF 文件路径 + 模型权重路径
- **输出**：检测结果 CSV + Shapefile（带地理坐标）

### generate_comparison.py — 结果对比

- **功能**：对比纯 RGB 检测 vs NDVI 辅助检测的结果差异
- **输出**：对比图表（`output/` 目录下的 PNG 文件）

## 使用方法

```bash
# 1. 切片 TIF
python tobacco_project/slice_tif.py

# 2. 全流程处理
python tobacco_project/tif_process.py --tif rs_data/result.tif --model models/best_large.pt

# 3. 对比分析
python tobacco_project/generate_comparison.py
```

## 输出文件说明

### Shapefile 文件组

每组 Shapefile 由 5 个文件组成，需一起使用：
- `.shp` — 几何数据
- `.dbf` — 属性数据
- `.prj` — 投影信息
- `.shx` — 空间索引
- `.cpg` — 编码格式

### CSV 检测结果

包含每张切片的检测结果：图片名、类别、置信度、边界框坐标等。
