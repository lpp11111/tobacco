# models/ — 训练好的模型权重

## 用途

存放所有训练完成的 YOLO 模型权重文件（.pt），供预测和评估使用。

## 模型清单

| 文件 | 大小 | 模型架构 | 类别数 | 类别 | 说明 |
|------|------|----------|--------|------|------|
| `best_extra_small.pt` | 49.6 MB | YOLOv8n | 2 | healthy, disease | 超高精度叶片识别模型（nano 轻量级） |
| `best_medium.pt` | 49.6 MB | YOLOv8m | 2 | healthy, disease | 中尺度病害检测模型 |
| `best_medium_finetuned.pt` | 49.6 MB | YOLOv8m | 2 | healthy, disease | medium 模型在 t 数据集上微调后的版本 |
| `best_small.pt` | 52.3 MB | YOLOv8m-seg | 4 | light_disease, healthy, severe_disease, moderate_disease | 小尺度病害分割模型（4 级病害分级） |
| `best_large.pt` | 52.3 MB | YOLOv8m-seg | 1 | tobacco | 大尺度烟草分割模型 |
| `best_t_scratch.pt` | 49.6 MB | YOLOv8m | 3 | grow_tobacco, disease_tobacco, others | t 数据集从零训练模型 |
| `best_t_transfer.pt` | 49.6 MB | YOLOv8m | 3 | grow_tobacco, disease_tobacco, others | t 数据集迁移学习模型 |

## 使用方法

```python
from ultralytics import YOLO

# 加载模型
model = YOLO('models/best_medium.pt')

# 预测
results = model('image.jpg')
```

或通过统一预测入口：

```bash
python predict.py --source image.jpg --model_type medium
```

## 模型选择建议

| 场景 | 推荐模型 | 原因 |
|------|----------|------|
| 病害检测（最佳性能） | `best_medium_finetuned.pt` | mAP50=0.826，微调后性能最优 |
| 病害分级（轻/中/重） | `best_small.pt` | 4 级病害分割 |
| 烟草区域提取 | `best_large.pt` | 分割烟草整体区域 |
| 轻量级部署 | `best_extra_small.pt` | nano 模型，速度快 |
| t 数据集任务 | `best_t_transfer.pt` | 迁移学习效果优于 scratch |
