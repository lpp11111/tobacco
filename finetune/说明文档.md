# finetune/ — 模型微调

## 用途

在 t 数据集上对 medium 病害检测模型进行微调训练，将 t 数据集的 3 类分割标签转换为 2 类检测框标签后训练。

## 目录结构

```
finetune/
├── finetune_medium.py          ← 微调训练主脚本
├── yolo26n.pt                  ← YOLOv8-nano 预训练权重 (5.3 MB)
├── yolov8m.pt                  ← YOLOv8-medium 预训练权重 (0.7 MB)
│
├── finetune_dataset/           ← 微调数据集（2类：healthy/disease）
│   ├── data.yaml               ← 数据集配置文件
│   ├── train/                  ← 训练集
│   │   ├── images/             ← 训练图片（~100 张 PNG）
│   │   ├── labels/             ← 训练标签（YOLO 检测框格式 .txt）
│   │   └── labels.cache        ← 标签缓存
│   └── val/                    ← 验证集
│       ├── images/             ← 验证图片（11 张 PNG）
│       └── labels/             ← 验证标签
│
├── finetune_medium/            ← 微调训练输出
│   └── finetune_medium/
│       ├── weights/            ← 模型权重
│       │   ├── best.pt         ← 最佳权重 (49.6 MB)
│       │   ├── last.pt         ← 最后一轮权重 (49.6 MB)
│       │   └── epoch*.pt       ← 各轮次权重 (197.8 MB/个)
│       ├── results.csv         ← 训练指标记录
│       ├── results.png         ← 训练曲线图
│       ├── confusion_matrix.png ← 混淆矩阵
│       ├── BoxF1_curve.png     ← F1 曲线
│       ├── BoxPR_curve.png     ← PR 曲线
│       ├── BoxP_curve.png      ← Precision 曲线
│       ├── BoxR_curve.png      ← Recall 曲线
│       ├── labels.jpg          ← 标签分布图
│       ├── train_batch*.jpg    ← 训练批次可视化
│       └── val_batch*_*.jpg    ← 验证批次可视化
│
└── runs/detect/val/            ← 验证过程可视化结果
    ├── confusion_matrix.png
    ├── BoxF1_curve.png
    ├── BoxPR_curve.png
    ├── BoxP_curve.png
    ├── BoxR_curve.png
    ├── val_batch0_labels.jpg
    └── val_batch0_pred.jpg
```

## 使用方法

```bash
# 运行微调训练
python finetune/finetune_medium.py
```

## 微调效果

微调后模型（`best_medium_finetuned.pt`）在 t 数据集上的性能：

| 指标 | 微调前（medium） | 微调后（finetuned） | 提升 |
|------|------------------|---------------------|------|
| Precision | 0.548 | 0.902 | +64.6% |
| Recall | 0.756 | 0.774 | +2.4% |
| mAP50 | 0.631 | 0.826 | +30.9% |
| mAP50-95 | 0.372 | 0.576 | +54.8% |
