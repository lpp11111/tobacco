# t/ — t 数据集训练

## 用途

基于 t 烟草遥感数据集的多种模型训练与对比。t 数据集为烟草遥感切片图像，共 3 类标注（grow_tobacco / disease_tobacco / others）。项目包含 4 种训练方案：从零训练、迁移学习、YOLOv8-m 训练、YOLOv8-nano 训练，并输出全部训练对比图。

│
├── data/                       ← t 数据集（3 类）

## 数据集类别

| 类别 ID | 类名 | 说明 |
|---------|------|------|
| 0 | grow_tobacco | 生长中的烟草 |
| 1 | disease_tobacco | 病害烟草 |
| 2 | others | 其他（非烟草） |

## 训练脚本对比

| 脚本 | 预训练权重 | 策略 | 输出模型 | Epochs |
|------|-----------|------|---------|--------|
| `TRAIN_scratch.py` | YOLOv8m (COCO) | 从零训练 | `best_t_scratch.pt` | 100 |
| `TRAIN_transfer.py` | `best_medium.pt` | 迁移学习 | `best_t_transfer.pt` | 100 |
| `train_t.py` | YOLOv8n (COCO) | nano 训练 | `best_t_nano.pt` | 300 |

## 训练结果对比

| 模型 | 脚本 | Epochs | Precision | Recall | mAP50 | mAP50-95 |
|------|------|--------|-----------|--------|-------|----------|
| t_scratch | `TRAIN_scratch.py` | 100 | 0.774 | 0.524 | 0.643 | 0.437 |
| t_transfer | `TRAIN_transfer.py` | 100 | 0.903 | 0.582 | 0.666 | 0.446 |
| **t_nano** | `train_t.py` | **300** | 0.733 | 0.772 | **0.748** | **0.543** |

### 关键发现

- **t_nano 综合最优**：mAP50 达 0.748，比 scratch 高 16.3%，比 transfer 高 12.3%
- **t_transfer 精度最高**：Precision 0.903，迁移学习带来高精确率
- **t_scratch 召回率最低**：从零训练缺乏先验知识，Recall 仅 0.524

## 使用方法

```bash
# 方式一：从零训练（推荐用于对比基准）
python t/TRAIN_scratch.py

# 方式二：迁移学习（利用 medium 模型知识）
python t/TRAIN_transfer.py

# 方式三：YOLOv8-nano 300轮训练（当前最优）
python t/train_t.py
```
