# t/ — t 数据集训练

## 用途

独立的 t 数据集训练流程，包含迁移学习和从零训练两种方式。t 数据集为烟草遥感切片图像，3 类标注（grow_tobacco/disease_tobacco/others）。

## 目录结构

```
t/
├── TRAIN_transfer.py           ← 迁移学习训练脚本（基于 medium 模型权重）
├── TRAIN_scratch.py            ← 从零训练脚本（YOLOv8m 基础权重）
├── yolo26n.pt                  ← YOLOv8-nano 预训练权重 (5.3 MB)
├── yolov8m-seg.pt              ← YOLOv8-medium-seg 预训练分割权重 (52.4 MB)
│
├── data/                       ← t 数据集（3类）
│   ├── data.yaml               ← 数据集配置文件
│   ├── train/                  ← 训练集
│   │   ├── images/             ← 训练图片（89 张 PNG，640×640）
│   │   ├── labels/             ← 训练标签（YOLO 格式 .txt）
│   │   └── labels.cache
│   ├── val/                    ← 验证集
│   │   ├── images/             ← 验证图片（11 张）
│   │   ├── labels/
│   │   └── labels.cache
│   └── test/                   ← 测试集
│       ├── images/             ← 测试图片（12 张）
│       └── labels/
│
├── t_train_transfer/           ← 迁移学习训练结果
│   ├── weights/                ← 模型权重
│   │   ├── best.pt             ← 最佳权重 (49.6 MB)
│   │   ├── last.pt             ← 最后一轮权重 (49.6 MB)
│   │   └── epoch0~90.pt        ← 各轮次权重 (197.8 MB/个)
│   ├── results.csv             ← 训练指标记录
│   ├── results.png             ← 训练曲线图
│   ├── confusion_matrix.png    ← 混淆矩阵
│   ├── BoxF1/PR/P/R_curve.png  ← 各指标曲线
│   ├── labels.jpg              ← 标签分布
│   ├── train_batch*.jpg        ← 训练批次可视化
│   └── val_batch*_*.jpg        ← 验证批次可视化
│
└── t_train_scratch/            ← 从零训练结果（结构同上）
```

## 使用方法

```bash
# 迁移学习训练（基于 medium 预训练权重）
python t/TRAIN_transfer.py

# 从零训练（YOLOv8m 基础结构）
python t/TRAIN_scratch.py
```

## 数据集类别

| 类别 ID | 类名 | 说明 |
|---------|------|------|
| 0 | grow_tobacco | 生长中的烟草 |
| 1 | disease_tobacco | 病害烟草 |
| 2 | others | 其他（非烟草） |

## 训练结果对比

| 模型 | 训练方式 | mAP50 | mAP50-95 |
|------|----------|-------|----------|
| t_transfer | 迁移学习 | 0.693 | 0.468 |
| t_scratch | 从零训练 | 0.649 | 0.446 |

> 迁移学习效果优于从零训练（mAP50 高 4.4%）。

## 图片命名规则

图片文件名包含地理坐标信息：
- `6.7_x10240_y15360.png` — 6月7日拍摄，坐标 (10240, 15360)
- `朱阁6.13_x14720_y8320.png` — 朱阁地区，6月13日拍摄，坐标 (14720, 8320)
