# 新数据集说明文档

## 1. 数据集概览

本数据集包含烟草种植区域的遥感影像数据，用于烟草病害检测与分割任务。

### 1.1 数据集位置

```
E:\tobacco\t
├── train/          # 训练集
├── valid/          # 验证集
├── data.yaml       # 数据集配置文件
├── TRAIN_transfer.py   # 迁移学习训练脚本
├── TRAIN_scratch.py    # 从头训练脚本
└── data_description.md # 数据说明文档
```

### 1.2 数据来源

数据集包含两个区域的烟草种植影像：
- **6.7区域**：普通烟草种植区
- **朱阁6.13区域**：朱阁地区烟草种植区

## 4. 标签格式

### 4.1 格式说明

本数据集使用 **YOLO分割格式**（polygon标注），每个标签文件对应一张图像。

### 4.2 格式规范

每行代表一个目标的标注，格式为：

```
{类别ID} {x1} {y1} {x2} {y2} {x3} {y3} {x4} {y4}
```

其中：
- `{类别ID}`：0-2的整数，对应上述类别定义
- `{x1}, {y1}, ..., {x4}, {y4}`：归一化的四边形顶点坐标（范围0-1）

### 4.3 示例

```
0 0.5859375 0.05859375 0.13125 0.05859375 0.13125 0.1140625 0.5859375 0.1140625
0 0.77421875 0.47578125 0.1421875 0.47578125 0.1421875 0.1484375 0.77421875 0.1484375
1 0.45703125 0.8140625 0.1421875 0.8140625 0.1421875 0.134375 0.45703125 0.134375
```

## 6. 训练脚本说明

### 6.1 迁移学习脚本 (TRAIN_transfer.py)

**原理**：将中尺度检测模型（YOLOv8m）训练学到的特征提取知识迁移到分割模型（YOLOv8m-seg）。

**步骤**：
1. 加载中尺度检测模型权重
2. 创建YOLOv8m-seg分割模型
3. 将检测模型中结构相同的层权重迁移到分割模型
4. 调整输出层适配3个类别
5. 在新数据集上进行微调训练

**输出目录**：`t_train_transfer/`

### 6.2 从头训练脚本 (TRAIN_scratch.py)

**原理**：使用YOLOv8m-seg原始COCO预训练权重进行训练，不使用中尺度模型的知识。

**步骤**：
1. 加载YOLOv8m-seg原始预训练模型
2. 调整输出层适配3个类别
3. 在新数据集上从头训练

**输出目录**：`t_train_scratch/`

### 6.3 训练参数

两个脚本使用相同的训练参数：

| 参数 | 值 | 说明 |
|------|-----|------|
| epochs | 100 | 训练轮数 |
| batch | 4 | 批次大小 |
| imgsz | 640 | 输入图像尺寸 |
| lr0 | 0.001 | 初始学习率 |
| cos_lr | True | 使用余弦学习率调度 |
| patience | 30 | 早停耐心值 |
| task | segment | 分割任务 |

## 7. 与中尺度数据集的差异对比

| 特性 | 中尺度数据集 (medium) | 新数据集 (t) |
|------|----------------------|-------------|
| 类别数 (nc) | 4 | 3 |
| 输入通道 (ch) | 4 (RGB+NDVI) | 3 (RGB) |
| 任务类型 | 目标检测 | 语义分割 |
| 标签格式 | bbox (5列) | polygon (9列) |
| 类别名 | light_disease, healthy, severe_disease, moderate_disease | grow tobacco, disease tobacco, others |
| 训练集大小 | 100+ | 89 |


## 9. 预期结果对比

迁移学习 vs 从头训练的预期差异：

| 对比项 | 迁移学习 | 从头训练 |
|--------|----------|----------|
| 收敛速度 | 快（利用已有知识） | 慢（从零学习） |
| 早期epoch精度 | 较高 | 较低 |
| 最终精度 | 可能更高 | 取决于数据量 |
| 过拟合风险 | 较低 | 较高 |
